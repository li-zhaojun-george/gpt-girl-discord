# Discord GPT 娘 · 2.0 核心版

![GPT 娘横幅](artwork/gpt-girl-banner-680x240.png)

白发龙娘前辈：会认真接话，也允许安静。支持 Codex 登录接入、受控群聊观察、明确保存的记忆和定时提醒。完整设计、借鉴来源及分阶段路线见 [UPDATE_PLAN.md](UPDATE_PLAN.md)。

## 已实现

- `MODEL_BACKEND=codex` 为默认：通过原生 CLI 的 `codex exec` 调用，使用部署机器上已有的 Codex 登录；不需要为此模式填写 OpenAI API key。
- `mention`、`observe`、`social` 三种参与模式。默认 mention；所有模式都要求非空频道白名单。
- 每人每频道最近6轮成功交流与短期群聊缓存保留30分钟；Codex回复前会根据语义按需从Discord读取更早的话题上下文，不再依赖这段缓存判断指代。
- `记住` 明确保存长期自述，最多10条；`不记录我` 停止把该用户在此频道的新消息送给模型。
- 明确命令创建提醒：持久保存、取消、安静时段延后、过期丢弃、重启不重复尝试发送。
- 日调用上限默认关闭，仍记录用量；串行模型调用、有界排队、失败退避。正常接话不受自行插话的冷却限制。
- 识别自然称呼、最近对话的无名字追问，以及指向其他人的 @ / 引用；可选 Codex 实时联网查证。
- 自主兴趣探索：按人设兴趣搜索，核验原站信息，分享简短看法、GIF/图片附件或视频原站链接；聊天时中断探索，持久去重。
- 可选自动记忆：从新群聊中整理普通个人喜好和共同话题，附消息证据、身份归属、过期时间与查看/更正/删除控制。
- 混合记忆检索：Codex 扩展相近表达，结合中文关键词、人物和发言日期找回仍有效的记忆，再回读来源核对；持续话题也按相关程度选择。详见 [第三阶段](docs/HYBRID_RETRIEVAL.md)。
- 结合话题与记忆参与群聊：无名字续话先判断是否在对她说；空闲时在关心未完话题、相关兴趣分享和安静之间选择。关心和分享共用节奏与 `/分享` 暂停控制，详见 [第四阶段](docs/PARTICIPATION.md)。
- 固定群聊回归：12个合成场景覆盖多人切换、隔天接续、喜好变化与误触发；支持离线集成检查、真实 Codex 重放及逐例 JSON 报告，见 [第五阶段](docs/REGRESSION.md)。
- 静态图片理解：沿用 Codex 登录，用实际图片输入读取 PNG/JPEG/静态 WebP/GIF 及 Discord 原生 PNG 贴纸；支持单发图、引用、连续追问，以及同一人30秒内先文字后贴纸的关联，见 [静态图片说明](docs/STATIC_IMAGES.md)。
- 表情包语境理解：区分可见画面、常见用法和本次含义，结合相关话题判断庆祝、自嘲、吐槽、附和等语气；普通接梗简短回应，缺少依据时不硬猜。见 [表情包语境](docs/MEME_CONTEXT.md)。
- 原 API 模式仍可显式选择，继续使用旧的每日0.10 CAD估算账本，无自动付费回退。

尚未实现：跨频道关系画像、自动生成日记或长期目标、动图/视频/语音理解、动画贴纸和自定义表情解析、QQ适配。自动记忆目前仅覆盖有来源的普通喜好和共同话题，不自动创建提醒。此版本不会假装这些能力已经存在。

## 首次运行或从旧版升级

需要 Python 3.11+、Discord Bot 和原生 Codex CLI。只运行一个机器人进程。

1. 停止旧进程。保留本机 `.env` 和 `daily-budget.sqlite3`；升级时不要覆盖凭证或清空预算。
2. 更新代码后创建环境、安装依赖。首次运行才复制模板：

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   # 仅在没有 .env 时执行：
   Copy-Item .env.example .env
   ```

3. 在部署机器、运行机器人的同一系统账号中执行 `codex login`，再用 `codex login status` 核对。
4. 合并 `.env.example` 的新字段到本机 `.env`。最少需要：

   ```dotenv
   DISCORD_BOT_TOKEN=你的机器人Token
   ALLOWED_CHANNEL_IDS=测试频道数字ID
   MODEL_BACKEND=codex
   BOT_MODE=mention
   CODEX_EXECUTABLE=codex
   ```

   Windows 若 PATH 找到的是 `.cmd` 或 `.ps1` 包装器，改填原生 `codex.exe` 完整路径。
   `CODEX_MODEL` 留空使用 CLI 默认模型；显式填写前确认部署账号能使用该模型。
   白名单多个ID用英文逗号分隔；空白现在会拒绝启动。线程使用线程自己的ID。

5. 可选运行一次真实连接自检（消耗一次 Codex 调用，只发送合成测试句子）：

   ```powershell
   .\.venv\Scripts\python.exe check_codex.py
   ```

6. 启动并在测试频道明确 @：

   ```powershell
   .\.venv\Scripts\python.exe bot.py
   ```

旧版 `.env` 没有 `MODEL_BACKEND` 时，这次升级会选 Codex。希望维持旧 API 路径时明确填写 `MODEL_BACKEND=openai`、`OPENAI_API_KEY`、`OPENAI_MODEL=gpt-6-luna`。不删除旧账本；切回 API 时继续累计当天已有用量。

`start.ps1` 仍可用于安装依赖和启动。本机关闭、休眠、网络断开时无法准时发送提醒。持续在线需要常开主机或服务进程。

## Discord 与参与模式

在 [Discord Developer Portal](https://discord.com/developers/applications) 创建 Bot，安装到服务器，授予 View Channels、Send Messages、Read Message History；线程另需 Send Messages in Threads。无需 Administrator、Members 或 Presence intent。

| 模式 | 普通消息 | 自动插话 |
| --- | --- | --- |
| mention（默认） | 不观察 | 不会 |
| observe | 只观察 OBSERVED_CHANNEL_IDS | 不会自行插话；回应称呼和正在进行的对话 |
| social | 只观察 OBSERVED_CHANNEL_IDS | 模型选择 reply / silence |

observe/social 必须同时开启 Developer Portal → Bot → **Message Content Intent**，并配置观察频道。观察频道必须是白名单的子集。在频道公开说明数据处理后再启用。例如：

```dotenv
BOT_MODE=observe
ALLOWED_CHANNEL_IDS=123456789
OBSERVED_CHANNEL_IDS=123456789
```

mention 模式不需要 Message Content Intent。正文明确 @ 最可靠；回复机器人时，仅在 Discord 实际提供正文且引用消息已解析时识别，不为分类主动拉取历史。私信、其他机器人及 webhook 消息忽略。

观察频道中的自然称呼（默认 GPT娘、大白龙、龙娘、小龙）可以开启对话。与她最近交流的同一用户，在同一频道的180秒内可不带名字继续追问；明确 @ 他人或回复他人会结束该用户的对话焦点。“不用回复了”“先不聊了”也能结束。该窗口是启发式判断，模型仍需结合语境判断是否转向别人。

隐式消息按每人每频道等待1.5秒，合并最多6条连续短句，锚定最新消息；明确 @ 立即处理。生成时收到更新，会丢弃过时回答，并处理最新内容。模型忙时正常对话进入有界队列，自行插话让路。队列超时或服务失败会提示；失败退避30秒。

`DAILY_MODEL_CALLS=-1` 和 `DAILY_SOCIAL_CALLS=-1` 默认关闭本地日上限；0表示禁用，正数表示日上限。判断沉默、失败、超时仍计数，账本不重置。自行插话默认每频道间隔30秒；称呼、@ 和接续追问不受此冷却影响。多伦多时间23:00–08:00不自行插话或发送提醒，正常对话继续。焦点和冷却为进程内状态，重启后需重新开启对话。

## 自主兴趣分享

配置 `INTEREST_CHANNEL_IDS` 后开启（默认留空关闭），要求这些频道同时属于观察白名单，且 `BOT_MODE=social`、`MODEL_BACKEND=codex`、`CODEX_WEB_SEARCH=live`。频道需 Send Messages、Attach Files 和 Embed Links；线程还需要相应发送权限。

兴趣来自可编辑的 `interests.json`：游戏巧思、动物与鲸鱼、泡面美食、科技与创作。按偏好权重选择主题，并降低连续选择同主题的概率；模型自行选具体角度，找不到好内容可以不发。当前不自动提取群友画像或根据反应训练兴趣。

首次安排在启动后的约5分钟；以后默认每90分钟上下浮动20%找一次机会，并非每次都发。聊天停顿至少120秒才开始，搜索中有新消息会取消并让正常对话优先。安静时段不探索或分享。发出一条后若无人再说话，暂停下一次分享；不会对着空频道连续发。没有新增日调用上限。

分享前核验搜索事件、读取原站标题和简介；失败时最多换一个来源。表情页解析图片/GIF，限制4MiB并检查格式；视频分享播放页链接，预览由Discord/原站决定，不下载整段视频。链接、相同标题或相同图片字节在同频道30天内去重。发送前保存“结果不确定”，超时或重启不自动重发。

所有人可 `@GPT娘 分享状态`；有“管理服务器”权限的人可 `@GPT娘 暂停分享` / `@GPT娘 恢复分享`，状态跨重启保留。关闭配置则彻底停止。详情与验收见 [INTEREST_SHARING.md](docs/INTEREST_SHARING.md)。

## 命令

以下命令在真实 `@GPT娘` 后输入；它们无需模型调用，在额度耗尽或模型忙碌时仍可执行。

| 命令 | 行为 |
| --- | --- |
| 帮助 | 使用说明 |
| 记住 喜欢下棋 | 保存你的明确自述，1–120字符 |
| 记忆 | 列出你在本频道的长期记忆 |
| 清空记忆 / reset | 删除你的长期记忆、交流和提醒，并清空本频道共享短期及衍生交流上下文 |
| 不记录我 | 清空上述内容，同时停止记录/向模型发送你在本频道的新消息 |
| 恢复记录 | 恢复短期记录；长期记忆仍需明确命令 |
| 提醒 30 复习 | 30分钟后在本频道发送提醒，不触发通知@ |
| 提醒列表 | 查看最近10条提醒及发送状态 |
| 取消提醒 123 | 取消属于你、尚未开始发送的提醒123 |

提醒分钟数1–43200，内容最多120字符；每人每频道最多5条待办，全局1000条。调度器每60秒检查一次，每频道每轮最多一条；延迟超过24小时失效。发送前检查频道白名单和当前权限。数据库先标记发送尝试，再调用 Discord：崩溃或网络结果不明时显示“发送结果不确定”，不自动重试，避免重复刷屏；它不保证必达。已开始发送的消息不能通过取消撤回。

## 记忆、隐私与运行限制

- 频道与用户 ID 用于隔离。模型输入包含当前发言者昵称、ID、相关文字、其显式记忆和成功交流；观察模式还包含该频道最近公开消息。不会自动读取当前 Codex 桌面聊天历史。
- 开启自动记忆的频道会从新消息提取普通偏好和共同话题，默认偏好90天、共同回忆180天、待确认候选7天过期；它不是永久画像或已核实的外部事实。
- 交流数据保存在 `data/state.sqlite3`，重启仍在；30分钟过期，由每分钟清理任务/读取时清理。群聊观察在内存中，重启消失；明确记忆直到删除，提醒结果最多保留到到期时间后7天。
- 清空会使尚未发送的相关生成失效，防止旧内容写回来；不能撤回已发消息、已发给供应商的请求或备份，也不能阻止别人重新引用你的话。开启自动记忆时，机器人在线收到原消息删除/正文编辑事件会清除相关自动记忆；离线期间的删除无法可靠追溯。无来源的手动「记住」内容仍需主动清空。
- Codex 每轮使用 `--ephemeral --ignore-user-config --ignore-rules`，临时空目录、只读沙箱、关闭 shell/apps/plugins/浏览器等工具，用应用传入的上下文维持连续性。通过 stdin 传资料，不拼接 shell 命令；子进程环境不传 Discord Token 或 OpenAI API key。
- 这不是完整的操作系统隔离；Codex 认证仍使用部署账号的本机登录。部署到群聊时宜用独立系统账号/专用主机，升级 CLI 后重新跑自检。当前验证版本 `codex-cli 0.165.0-alpha.1.2`；不支持相关参数的版本会失败，不会自动放宽限制。
- 日调用次数是本地阀门，不等于 ChatGPT/Codex 实际剩余额度或费用上限；供应商限额仍适用。没有实时余额查询，不编造数字。
- API 的 `store=False` 与 Codex 的 ephemeral 都不等于供应商完全无日志。程序不把聊天、密钥或模型错误响应体写入应用日志；记录决策、发送是否成功和错误类型。
- 当前只处理文字。Codex 后端设置 `CODEX_WEB_SEARCH=live` 可使用原生联网搜索；默认 disabled，API 后端未接搜索。事实查证应带真实来源链接，不确定时不能把用户反对当作证据直接改数字。
- 搜索提示要求只使用必要公开主题词，不带用户ID、昵称或私人记忆；这是模型指令约束，不是搜索查询的程序级过滤器。网页内容作为资料，不授权执行。
- 可根据话题检索并分享实际找到的网页、表情包页面或视频链接；已支持可选后台兴趣探索和表情图片/GIF附件发送；仍未实现图片理解或视频观看。不会运行群友代码、控制电脑或修改服务器。

## Discord 原生 / 指令

Codex在准备回复时会根据文字语义判断上下文是否足够：先读15条，必要时继续向前读，找到话题起点和相关的多人讨论；无需“上一句/⬆”指令词。Discord回复引用优先，找不到就询问，不拿历史分享补猜。读取仅用于本次回答，不加入自动记忆，详见 [MESSAGE_REFERENCES.md](docs/MESSAGE_REFERENCES.md)。

自动记忆频道现在另有持久化话题状态：后台整理参与者、背景、进展、未完问题和约定；保存摘要与来源索引，重启后可接续。回复前重新核对原消息，编辑、删除或退出记录会使相关状态失效。`/状态` 可查看已整理的话题数量。第一阶段范围与验收见 [TOPIC_STATE.md](docs/TOPIC_STATE.md)。

第二阶段已将人物喜好和共同经历接入当前话题：根据语义挑选相关记忆，重新读取来源并确认含义后与话题原文一起回答。当前需求和明确更正优先，不把其他人的偏好归给当前用户；独立知识问题可不引用任何记忆。详见 [MEMORY_CONTEXT.md](docs/MEMORY_CONTEXT.md)。

已支持按频道名称选择聊天与主动分享方向：游戏、学习、桌游、欣赏、吃瓜和表情等；图片频道发图片/GIF，主动视频只在视频频道搜索和发送，普通聊天频道不接收主动视频投递。通过明确白名单开启更多频道，语音频道支持文字聊天。用 `/状态` 查看当前方向，详见 [CHANNELS.md](docs/CHANNELS.md)。

在已启用的频道输入 `/`，选择GPT娘即可使用原生菜单，不必再先@。操作结果默认仅自己可见，不进入群聊上下文，也不调用模型。到期提醒仍公开发在创建时的频道。

| 示例 | 用途 |
| --- | --- |
| `/帮助`、`/状态` | 查看菜单、后端、模式和个人记录设置 |
| `/用量` | 查看今日机器人本地调用次数，不是Token账单或Pro剩余额度 |
| `/记忆 查看`、`/记忆 自动`、`/记忆 共同` | 查看自己的记忆或本频道共同回忆 |
| `/记忆 保存 内容:喜欢乌龙茶` | 明确保留自己的偏好 |
| `/记忆 来源 编号:1` | 核对证据；私密指令来源不伪造公开消息链接 |
| `/记忆 更正 编号:1 内容:现在更喜欢红茶` | 修订自己的喜好或参与的回忆；另有确认、删除、清空 |
| `/提醒 创建 分钟:30 内容:休息一下` | 创建提醒；另有列表、取消 |
| `/分享 状态`、`/分享 暂停`、`/分享 恢复` | 查看主动分享；暂停与恢复需要管理服务器权限 |
| `/记录 停止`、`/记录 恢复` | 清除并退出记录，或恢复记录新消息 |

启动时仅向已启用频道所属服务器同步指令；原有@文字命令继续可用。完整说明和验收见 [SLASH_COMMANDS.md](docs/SLASH_COMMANDS.md)。

## 自动记忆与共同回忆

现已按管理员要求在当前23个已启用聊天位置部署自动记忆，各频道独立保存与检索，语音频道仅处理文字区。配置与验证见 [MULTICHANNEL_MEMORY.md](docs/MULTICHANNEL_MEMORY.md)。

`AUTO_MEMORY_CHANNEL_IDS` 默认留空关闭；配置后仅在指定观察频道、Codex后端生效，从上线后的新交流开始，不回读历史。上线会发一条简短说明。空闲约12秒后批量整理，正常对话优先；提取阶段关闭搜索与工具。

明确表达的饮食、游戏、影视音乐、爱好、聊天方式可成为有来源的记忆。含糊、玩笑、单人回忆先作为候选，候选不用于确定性回答。共同回忆注明实际发言来源，不等于GPT娘在线下参与。健康、财务、政治宗教、亲密关系和联系方式等不自动整理；规则和模型筛选可能误判，可随时纠正或删除。

- `@GPT娘 记忆`：手动记忆与自己的自动喜好摘要。
- `自动记忆`、`共同回忆`：查看自己的自动喜好、当前频道共同话题及编号。
- `记忆来源 编号`：查看短证据与原消息链接。
- `更正记忆 编号 新内容`、`确认记忆 编号`、`忘记记忆 编号`：管理自己的喜好或自己参与的回忆。
- `清空记忆` / `不记录我`：同时清除涉及自己的自动记忆和共同证据，并使尚未完成的整理失效；后者也停止记录新消息。

有效喜好90天、共同回忆180天过期，不再因新增记录超过20/50条而删除较早的有效记忆。仅保存摘要和最多4段短证据，不保存完整群聊日志；原文缓冲30分钟内清理。普通聊天从本频道全部仍有效的记录中检索，兴趣搜索不接收这些记忆。详见 [SOCIAL_MEMORY.md](docs/SOCIAL_MEMORY.md)。

## API 估算预算

只有显式 openai 后端使用根目录原有 `daily-budget.sqlite3`。全体用户共用每日0.10 CAD，多伦多时间零点切换；输入输出计价系数沿用旧版（保守输入200、输出800，单位为十亿分之一CAD/token），这不是实时价格或账单承诺。换模型或供应商调价时应先核对官方计价并修改 `budget.py`。

请求前预留、成功后按 usage 结算；未知结果保留预留，不自动重试。过大的请求被拒绝后，较小请求仍可尝试。不要删除账本来重置额度；该保护不涵盖其他应用调用、税费或未来调价。
