# 原生 / 指令

7个入口：用量、帮助、状态、记忆、提醒、分享、记录，共20个可执行指令。服务器内已启用频道可使用；其他频道会收到私密提示。输入 `/记忆` 后从菜单选子指令，不需要同时@机器人。

## 行为与权限

- 全部控制结果仅操作者可见，不加入公开对话或自动记忆提取缓冲；管理指令直接调用既有服务，不消耗模型调用。
- 用量按机器人配置时区统计今日总调用、主动判断及兴趣探索、聊天及记忆整理，包含模型沉默、失败及超时尝试；没有查询Pro账户剩余额度或Token账单。
- 查看个人记忆、修订、删除、提醒列表和取消沿用用户及频道隔离。共同回忆可由频道成员查看；修订、确认与删除要求本人参与。私密指令产生的证据明确标记，没有公开消息链接。
- `/记忆 清空` 默认只说明影响，需要将“确认”设为True才执行。会清除本人记忆、相关共同回忆、提醒与共享短期上下文。
- `/记录 停止` 清除相关内容并停止记录新消息；恢复不找回已删除内容。
- `/提醒 创建` 分钟范围1–43200，内容1–120字。创建反馈私密，但到期后公开发到当前频道，不触发@通知；沿用安静时段与现有调度、容量和幂等规则。
- `/分享 暂停` 与 `/分享 恢复` 检查“管理服务器”权限，普通成员可查状态。不会改变正常聊天模式。
- 启动后根据已启用频道确定服务器并同步，每个连接生命周期成功一次；重连可重试失败同步。发现其他未知服务器指令会跳过同步并记日志，避免批量覆盖它们。不发布全局指令。

## 验证

99项自动测试通过，新增9项覆盖菜单结构与参数、频道限制、私密响应、无模型调用、个人归属、退出记录、清空确认、管理员检查、证据链接及同步保护。

部署后需核对Discord返回的7个入口与20个可执行指令；真人在次要聊天输入 `/用量` 和 `/记忆 查看`，确认菜单、响应和“仅自己可见”。服务端注册成功与用户实际调用分别验收。

实现基于discord.py的[应用指令接口](https://discordpy.readthedocs.io/en/stable/interactions/api.html)。
