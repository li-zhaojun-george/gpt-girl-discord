# 第四阶段：结合话题和记忆参与群聊

正常接话、主动关心和分享现在使用一致的上下文结构：已核对的话题原文、话题进展和待续事项、第三阶段检索出的相关记忆、当前频道近期消息，以及机器人刚说过的话。

## 接话

明确 @ 或称呼照常回应。无名字的短时追问与普通插话，先通过关闭搜索的 Codex 判断说话对象和是否值得接话；判定对别人说或对象不清时程序停止生成回答。近期聊过仅是线索，不能据此冒充其他群友。没有结构化能力的旧后端保持原路径。

生成回答继续结合实际上下文和记忆；话题已解析时仍保留最近自身发言以避免重复。判断失败时这次隐式接话保持安静，明确叫她不受这个可选判断阻挡。判断额外占一次本地调用计数，无新增日上限。

## 空闲时的选择

沿用 `INTEREST_CHANNEL_IDS` 的主动参与范围。在已启用自动记忆的频道，先读取最多20条、24小时内的实际消息，过滤退出记录、敏感内容与其他机器人。取得第三阶段已核对的话题和相关记忆后，关闭搜索进行规划，选择其中一种：

- `check_in`：围绕有来源的未完普通话题自然问一句，实际参与者需最近24小时在本频道发过言；不把旧偏好编成待办、不追问已经完成或明确不想聊的事。只在普通聊天频道发送，不通知 @。
- `share`：结合话题和喜好，从该频道已有的公开兴趣方向中选择，再搜索、核对原站、写分享语。未找到相关方向时可按自身兴趣分享，不能假装是专门为群友找到的。
- `silence`：现在没有自然的参与机会，什么也不发。

没有可读的近期人类消息或无法核对上下文时，本轮跳过。未开启自动记忆的兴趣频道保持原自主分享模式。后台收集最长65秒、规划最长25秒，可被聊天打断；正常对话优先。

## 联网与分享

群聊和记忆只参与关闭搜索的规划与文案步骤。联网阶段收到的仍是既有公开兴趣清单、原站范围和公开分享标题，不带群友ID、昵称、聊天全文或记忆。不会用自由生成的私人检索词替换公开兴趣清单。

文案阶段关闭搜索，结合已核验标题简介与话题记忆，自然说明一个相关联想。原有频道主题、视频只投视频频道、表情附件、URL与内容去重规则继续生效。没有增加图片理解或观看完整视频的能力。

## 节奏和管理

关心与分享使用同一调度器、暂停状态和等待回应状态。沿用配置的约90分钟机会间隔、120秒聊天让路、服务器至少20分钟主动发言间隔，以及23:00–08:00安静时段；具体配置沿用部署值，不保证每次机会都发言。

同一话题30天内最多主动关心一次。发送前持久标记尝试，断网或重启不重发不确定的消息；没有人回应时不继续主动发言。明确“先不聊了”等结束语同样等待新的群友发言。新消息、清空记忆、退出记录、改名或权限变化会使在途动作取消或失效。

`/分享 状态、暂停、恢复` 同时管理主动分享与话题关心；暂停/恢复仍需管理服务器权限。`/状态`、`/帮助` 已更新说明。新增 `participation_actions` 只保存频道、话题ID、目标用户ID、发送状态/消息ID与时间，不另存私聊或原文；清空记忆清理本频道相关派生标记。原配置、原记忆无需迁移或重新导入。
