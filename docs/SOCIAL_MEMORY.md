# 喜好与共同回忆 · 2026-10-28

修改前检查点为 `9af280a`：兴趣分享代码、实际视频发送与用户验收均已保存到GitHub。本轮从新的群聊交流中整理可追溯的普通喜好和共同话题，形成有依据的连续感。

## 保存与使用

- 仅在 `AUTO_MEMORY_CHANNEL_IDS` 指定的观察频道生效，默认关闭，需要Codex后端。不回读旧消息，不跨频道合并身份画像。
- 人格偏好范围：饮食、游戏、影视音乐、爱好、聊天称呼或表达方式。只记本人自述；程序检查作者、消息ID和原文摘录，模型负责判断具体语义。
- 明确偏好成为有效记忆；含糊、玩笑和单人回忆保留为候选，候选不进入日常确定性回答。共同回忆需要真实发言证据，不代表GPT娘参加了线下活动。
- 每条保存主题、摘要、状态、来源、更新时间与期限。最多4段短证据，每段4–180字；不持久保存完整群聊原文。待整理的原文仅在内存，最多30条/频道、30分钟。
- 有效偏好90天、共同回忆180天、候选7天过期；每人每频道最多20条偏好，每频道50条共同回忆。确认/更正的条目90天过期，后续自动提取不覆盖人工修订。
- 同主题的新明确自述可以更新旧自动喜好；猜测和更早消息不覆盖已有明确内容。主题归一由模型辅助，语义重复或理解错误仍可能发生。
- 正常聊天只取当前发言者、少量相关参与者的有效偏好以及本频道近期共同话题。明确手动记忆与当前发言优先；人格要求适度使用，不背档案、不推导好感度或排他关系。

## 整理与隐私控制

聊天空隙约12秒后批量整理；每批最多6条候选输出。普通对话优先，可以打断整理。整理器复制现有Codex适配器并关闭web_search，其他工具仍关闭。自主兴趣搜索不接收这些群友记忆。

自动排除健康诊断、财务、政治宗教、性和亲密关系、精确联系方式、密码等敏感内容，结合保守字符串过滤和模型规则；这不是完美分类器，仍需人工纠错渠道。

上线会在目标频道发一次简短说明，不通知@。所有控制命令无需模型理解：

| 命令（@GPT娘后） | 行为 |
| --- | --- |
| 记忆 / 自动记忆 | 查看手动内容/自己的自动喜好与编号 |
| 共同回忆 | 查看当前频道的共同话题和候选 |
| 记忆来源 编号 | 查看证据短句与原消息链接 |
| 确认记忆 编号 | 确认自己的喜好或自己参与的候选回忆 |
| 更正记忆 编号 内容 | 人工修订并保存本次命令为来源 |
| 忘记记忆 编号 | 删除自己的喜好或自己参与的回忆 |
| 清空记忆 | 删除自己的手动与自动内容、涉及自己的共同证据、提醒及衍生短期内容 |
| 不记录我 / 恢复记录 | 清除并停止记录/恢复记录新消息 |

涉及共同证据的删除会保守删除整条共同回忆。清空和更正会使在途提取/回答失效，避免重新写回旧内容。机器人在线收到原文删除或正文编辑事件时删除关联自动记忆；离线遗漏的事件无法可靠追溯。手动「记住」没有原文证据关联，仍用命令清除。删除不会撤回已发Discord消息、供应商已接收请求或历史备份。
