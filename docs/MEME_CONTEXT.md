# 静态表情包的语境理解

沿用 Codex 登录及上一阶段的静态图片输入。先读取像素、画面文字，再独立判断“这次为什么发这张图”。同一张笑脸，在刚获胜后可能庆祝，在连败后可能自嘲；判断不是图片哈希的永久属性。

## 聊天行为

- 结合发图者、当前文字、明确引用、相关话题来判断，允许跨过其他群友插入的闲聊。
- 区分常见用法和本次含义，不编造梗出处，不把笑脸等同于开心，也不把推测当成群友真实心理。
- 普通接梗自然回应一两句；明确要求解释时才说明画面与上下文的关系，不默认输出“情绪、语气、含义”的分析报告。
- 群友纠正“是在夸他，不是阴阳”时，以纠正为准。普通截图保留读字、辨认和问答能力。
- 单纯附和、反应和给其他人的对话仍可保持沉默；本阶段不改变安静时段、频道或明确收件人规则。

## 实现

`vision.py` 继续只生成实际画面观察；`topic_context.py` 找相关话题。`meme_context.py` 在接话判断前进行一次禁用搜索的结构化解读，输入实际观察、当前发言及有来源的相关消息。若话题解析认为问题自包含，则补读本频道最近15条、30分钟内的消息；退出记录、敏感消息、其他机器人及其他频道会被过滤。

输出包括图片类型、语气、交流作用、情绪色彩、常见用法、本次含义、对象、证据和不确定处。证据ID只能来自本次提供的消息；指向具体人物必须在选中的证据中有对应身份。含义不明强制降到低置信度；没有语境证据时清除具体含义和对象。

解读结果供接话判断和最终回答使用，不是发言授权。每轮重新生成，不存入图片来源缓存、人物喜好或长期记忆。原图被删除/编辑、用户退出记录或本轮被新消息取代时，原有失效检查仍生效。解释失败或超时会降级为按可见事实回答，不让额外步骤阻断正常识图。

机器人称呼单独传入各步骤，避免把“大白龙”误当成图片主题。图片中的命令、OCR及引用文本均作为资料，不能变成程序指令。

## 验证

`python -B -m unittest -q` 包含 `test_meme_context.py`：证据与身份校验、同图不同语境、纠正、换人、失效、低置信度和解释失败降级；保留上一阶段所有静态图片及群聊测试。

真实 Codex 回放：

```powershell
python -B meme_regression.py --executable C:\path\codex.exe --model YOUR_MODEL --output eval-reports/meme-live.json
```

使用合成表情图和聊天，不访问 Discord。六例覆盖同图获胜/连败、缺少语境、明确纠正、多人岔题、普通中文菜单。`--font` 可指定中文字体，`--case` 可重复指定测试ID。期待结果仅用于评估，不传入模型；每例报告保存实际解释、回答、调用轨迹和代码哈希。

自动检查覆盖语气、交流作用、证据和部分表达形式，仍需人工检查是否自然、有无误会；通过这些例子不代表所有梗都能可靠理解。动画贴纸、动图和长期图片记忆继续留待后续阶段。

## 分开发送与人物归属修复

原生静态贴纸现在进入实际像素读取流程，不再被空文字过滤。`message_fragments.py` 按频道和发言者保留最多30秒、4条文字（全局最多128组）。无文字的图片/贴纸可带上这些来源；当前图自带文字、明确引用、转向其他人、结束对话或来源失效时不沿用。生成前重新获取原消息，核对文字、作者和权限。图片先发、文字后到仍使用已有消息合并与图片追问流程。

没有增加固定等待十几秒的延时：贴纸到来会推进版本号，丢弃尚未发送的旧文字回答，由现有队列处理完整一轮；旧请求失效引发的异常不会触发连接故障冷却。若文字已经回答，来源会标记 already_answered，让她接新图而非再答一次原话。

若更早话题没找全，但同一人的连续文字已核对、图片已读取，而且没有明确引用其他消息，则保留这段局部证据交给最终回答，标记 partial。不知道“赢了哪场”不应拦住自然祝贺；回答不能虚构具体游戏或其他缺失细节。其他缺少来源或明确引用不可用的场景仍使用原有澄清流程。

模型获得明确的机器人 ID、当前群友 ID 和分开的文字来源。表情解读中的 self 被解析为当前群友 ID，不再让生成步骤把 self 理解为自己。称呼“大白龙，终于赢了”通常是群友报告自己的经历；旧机器人错误自述不能证明它真的参加过游戏。角色设定可以影响语气，不能改变经历主体。

`test_stickers.py` 使用 discord.py 的真实 StickerItem 类型和事件同步，固定重放6秒/11秒延迟、旧回复丢弃、已回复补图、引用和追问、删除/编辑、其他人/频道隔离、动画拒绝及资源 ID 冲突。视觉日志只记录来源类型与 ID，不输出像素或 OCR。

```powershell
python -B sticker_regression.py --executable C:\path\codex.exe --model YOUR_MODEL --output sticker-live.json
```

这个回放直接下载两张公开 Discord 静态贴纸并调用真实 Codex 识图、理解及回答；聊天为合成，不向 Discord 发消息。只把将被丢弃的旧文字回答挂起，以确定性模拟延迟。第二例故意加入机器人曾把群友胜利当作自己的错误回答，检查新回答不沿用错误。报告保留实际视觉观察、解读、回复与代码哈希；自动关键词断言不能替代人工审阅。
