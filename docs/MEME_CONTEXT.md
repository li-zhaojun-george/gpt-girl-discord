# 静态表情包的语境理解

沿用 Codex 登录及上一阶段的静态图片输入。先读取像素、画面文字，再独立判断“这次为什么发这张图”。同一张笑脸，在刚获胜后可能庆祝，在连败后可能自嘲；判断不是图片哈希的永久属性。

## 聊天行为

- 结合发图者、当前文字、明确引用、相关话题来判断，允许跨过其他群友插入的闲聊。
- 区分常见用法和本次含义，不编造梗出处，不把笑脸等同于开心，也不把推测当成群友真实心理。
- 普通接梗自然回应一两句；明确要求解释时才说明画面与上下文的关系，不默认输出“情绪、语气、含义”的分析报告。
- 群友纠正“是在夸他，不是阴阳”时，以纠正为准。普通截图保留读字、辨认和问答能力。
- 单纯附和、反应和给其他人的对话仍可保持沉默；本阶段不改变安静时段、频道或明确收件人规则。

## 实现

`vision.py` 继续只生成实际画面观察；`topic_context.py` 找相关话题。`meme_context.py` 在接话判断前进行一次禁用搜索的结构化解读，输入实际观察、当前发言及有来源的相关消息。若话题解析认为问题自包含，则补读本频道最近15条、30分钟内的消息；退出记录、敏感消息、其他机器人及其他频道会被过滤。

输出包括图片类型、语气、交流作用、情绪色彩、常见用法、本次含义、对象、证据和不确定处。证据ID只能来自本次提供的消息；指向具体人物必须在选中的证据中有对应身份。含义不明强制降到低置信度；没有语境证据时清除具体含义和对象。

解读结果供接话判断和最终回答使用，不是发言授权。每轮重新生成，不存入图片来源缓存、人物喜好或长期记忆。原图被删除/编辑、用户退出记录或本轮被新消息取代时，原有失效检查仍生效。解释失败或超时会降级为按可见事实回答，不让额外步骤阻断正常识图。

机器人称呼单独传入各步骤，避免把“大白龙”误当成图片主题。图片中的命令、OCR及引用文本均作为资料，不能变成程序指令。

## 验证

`python -B -m unittest -q` 包含 `test_meme_context.py`：证据与身份校验、同图不同语境、纠正、换人、失效、低置信度和解释失败降级；保留上一阶段所有静态图片及群聊测试。

真实 Codex 回放：

```powershell
python -B meme_regression.py --executable C:\path\codex.exe --model YOUR_MODEL --output eval-reports/meme-live.json
```

使用合成表情图和聊天，不访问 Discord。六例覆盖同图获胜/连败、缺少语境、明确纠正、多人岔题、普通中文菜单。`--font` 可指定中文字体，`--case` 可重复指定测试ID。期待结果仅用于评估，不传入模型；每例报告保存实际解释、回答、调用轨迹和代码哈希。

自动检查覆盖语气、交流作用、证据和部分表达形式，仍需人工检查是否自然、有无误会；通过这些例子不代表所有梗都能可靠理解。GIF、动画、贴纸和长期图片记忆继续留待后续阶段。
