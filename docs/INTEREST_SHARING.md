# 自主兴趣分享 · 2026-10-28

修改前核对GitHub检查点 `7bc842e` 与本机/部署代码；此前连续群聊与验收记录均已同步。本轮增加自主兴趣搜索，不改变Codex登录后端。

## 工作方式

1. 从 `interests.json` 的游戏巧思、动物与鲸鱼、泡面美食、科技创作中按偏好选择主题，降低刚分享过的主题权重。模型自行选具体切入点。

第四阶段已在自动记忆频道增加前置参与判断：先结合已核对话题与相关记忆，选择关心、分享或安静；选择分享时再进入以下公开搜索流程。文案步骤关闭搜索并加入同频道上下文。详情和共用节奏、暂停控制见 [PARTICIPATION.md](PARTICIPATION.md)。
2. 用Codex原生搜索找候选，必须有实际完成的搜索工具事件。输入只有公开兴趣、时间与她自己的分享记录，不传群友昵称、ID、聊天或私人记忆。
3. 程序单独读取原站标题/简介；不可用时最多换一个来源。不用搜索页、目录页代替具体视频或表情。
4. 从已核验元数据生成最终中文短话，表达兴趣、联想或自然话头。搜索时的候选文案不会直接发布。
5. 视频发原站播放链接，Discord自行决定预览；表情页提取图片/GIF/WebP，核验类型和文件头、限制4MiB，再上传为附件并附来源。
6. 发送前再次确认频道权限、安静时段、暂停状态和期间是否有人说话。先持久记录发送尝试，避免重启或网络不确定时重复发送。

实现使用 `codex exec --json` 搜索事件和结构化结果，参见 [官方非交互模式](https://learn.chatgpt.com/docs/non-interactive-mode) 与 [搜索说明](https://learn.chatgpt.com/docs/web-search)。

## 节奏与打断

- 默认关闭，新配置 `INTEREST_CHANNEL_IDS` 指定允许主动分享的观察频道；本次上线范围沿用原测试频道。
- 首次机会约5分钟后；以后约90分钟上下浮动20%。这是寻找机会的节奏，模型可选择沉默，不是强制发帖任务。
- 群里最近120秒有人聊天时让路；探索途中出现新消息会取消，释放模型给正常聊天，并延后10分钟。
- 23:00–08:00使用已有多伦多安静时段。程序关机或离线不补发堆积内容。
- 上一条分享后无人再发言则等待回应；不会连续自说自话。没有新增日次数上限，既有本地日限继续为-1。
- URL去掉追踪参数，并统一YouTube短链等形式；同频道30天内相同链接、相同标题或相同图片字节不再分享。
- 分享后的短时无名字追问可接续，回复输入包含真实分享的标题、简介和来源。

## 控制、存储和边界

`@GPT娘 分享状态` 任何人可用；`暂停分享`、`恢复分享` 需要Discord“管理服务器”权限。暂停跨重启保存。配置留空可彻底关闭。

SQLite新增 `interest_schedule`（时间、暂停与等待回应状态）和 `interest_shares`（自己分享的公开来源、文案与发送状态）。不保存搜索过程或下载文件，临时搜索轨迹随调用目录删除；附件下载仅存在内存。正常应用日志不记录聊天、凭证或搜索返回全文。

来源/CDN有独立域名清单，HTTPS且每次跳转重新验证；DNS解析阻止非公网地址。HTML最多读取前1.5MB，图片读取有硬大小限制。网页内容和元数据始终作为资料。Shell、插件、电脑控制等仍关闭。

人格兴趣是可编辑的偏好清单，不是自动训练出来的意识或关系画像。模型尚不能观看完整视频或理解图片像素；分享文案只依据标题简介，不能声称亲自看过。自动测试无法证明每条生成文案都准确或自然，需结合真实群聊反馈继续调整。
