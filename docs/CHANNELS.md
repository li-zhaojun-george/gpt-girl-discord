# 按频道参与聊天

普通回复与主动搜索均传入当前频道名称、分类、简介和推导的用途；这些文本是资料，不具有指令权限。频道名称决定默认话题，当前群友的具体问题优先。上下文和记忆仍按频道隔离，不跨频道搬运聊天。

| 频道名称关键词 | 方向 |
| --- | --- |
| 游戏、电竞 | 游戏机制、合作、创意与趣事 |
| 学习、知识、技术 | 科学、编程、学习方法 |
| 桌游、棋牌 | 桌游规则、策略与聚会玩法 |
| 欣赏 | 全年龄绘画、摄影、音乐与动画 |
| 吃瓜 | 可核对来源的公开游戏/科技趣事 |
| 表情、整活 | 轻松幽默、动物与反应表情 |
| 其他 | 日常聊天、动物、食物、冷知识 |

名称含“图片/表情包”时主动分享只使用现有表情原站的图片/GIF；含“视频”时只选具体视频。当前仍没有图片理解、视频观看或任意图库下载能力。相关性由搜索和分享文案两阶段判断，格式由代码限制，不能保证所有内容都匹配。

公告、规则、人员变动、日志、待机及明确成人内容频道不主动搜索分享。正常文字回复仍遵守既有规则与权限。语音频道接入的是其中的文字聊天，不加入语音通话。

同服务器主动分享至少间隔20分钟，时间保存在数据库，重启不会立即重发；各频道原有90分钟左右巡游、无人回应等待、安静时段和聊天优先仍有效。优先巡视最早到期频道，防止固定频道抢占；同服务器内URL和内容指纹去重。改名后的新请求重新判断方向，生成过程中发现用途改变则放弃分享。

部署按实际可见且有发言权限的文字/语音频道更新明确白名单，不修改Discord权限。新建频道仍需加入白名单；改名不需要重新部署。自动记忆开启范围单独配置，不会因扩大聊天范围自动扩大长期记录。本轮经用户明确要求，将现有23个聊天位置同时加入自动记忆范围，详见 [MULTICHANNEL_MEMORY.md](MULTICHANNEL_MEMORY.md)。

`/状态` 显示当前方向，`/分享 状态` 查看是否启用；管理员可按频道暂停/恢复主动分享。106项自动测试覆盖原有功能与主题/格式、普通聊天上下文、跨频道节奏与去重、改名失效、巡视公平性。

用户已在游戏聊天与学习聊天确认 `/状态` 方向正确、无@接话正常且内容符合频道用途。原生 `/用量`、`/记忆 查看` 的菜单调用与仅本人可见回复也已由用户验收。
