# 聊天指代定位

“上一句/上一条/上面/前面/上文/⬆/↑”曾只依赖30分钟内存上下文。原文过期或重启后不可见，持久化的旧分享可能被模型误当作指代对象。

现在明确对话触发上述表达时，按当前消息位置向前检查同频道最多20条、24小时内的消息，优先定位最近的群友发言；跳过机器人消息及当前用户完全重复的请求。Discord回复引用优先，按引用ID重新读取最新原文。引用不可跨频道，也不向模型传递已退出当前频道记录者的消息。

检索仅发生在这次明确请求中，不批量回读、不写入自动记忆提取队列。原文按2000字符限制，附件只标记存在，不假装理解图片。模型输入明确给出引用对象，同时移除旧分享、过去交流、旧自动记忆等可能误导指代的上下文；无法获取原文时直接请用户回复原消息或贴原文，不由模型猜测。

默认“上面”解释为前面的群友聊天；想评论机器人发过的某条视频、图片或回复，应使用Discord回复功能准确定位。

120项自动测试通过，覆盖过期聊天在重启后的定位、明确回复优先、跨频道拒绝、退出记录、时间及条数限制、缺少权限和无法定位时不调用模型补猜。普通聊天不会触发历史读取。
